Window handle repair and replacement

Handles we replace

  • Folding and fixed crank handles on casement and awning windows
  • Lever handles on tilt and turn and European windows
  • Lock handles on sliding windows and patio doors
  • Locking handles with keys

Handle or operator?

If the handle spins freely on its shaft, the handle itself or the splined shaft is worn. If the handle turns but the window doesn't move, the gears in the crank operator are stripped. We check which one it is and replace only what's needed. See window crank repair.

Matching colours

Handles come in white, almond, bronze, black and other finishes. We match the colour and style of your other windows.

Common questions

My crank handle spins without opening the window. Is it the handle?

Sometimes. If the handle is loose on the shaft, it's the handle. If the shaft turns but the window doesn't move, it's the operator. We check and replace the right part.
